# M8: Page tools

Status: **in progress** (2026-10-14), branch `m8` (cut from `cleanup-cli`).
One commit per slice; notes per slice at the end.

## Decided at kickoff (2026-10-14)

**Generated pages are files.** Every source in the document model is a
PDF on disk. Save, incremental save, recovery and the renderer all reopen
it by path. Pages made from images and blank pages are therefore written
as small PDFs to a content-addressed cache directory
(`<cache>/sheaf/generated/<hash>.pdf`) and added as ordinary sources. Being
content-addressed, a file survives a crash, so recovery can still find it,
and the same image inserted twice is one file. Nothing deletes them yet;
they're small, and a cache cleanup can come later.

**Operations go in `sheaf-ops` when the command line needs them**, as in
the ops/CLI plan: combine and split (both get subcommands). Insert, crop,
labels and stamps are document edits in `sheaf-doc`, which the GUI drives.

**Combine Files writes a file and opens it.** Acrobat makes an untitled
document. sheaf documents are files, so Combine asks where to save first,
as File > Create > From Scans/Photos does.

**Headers, footers, Bates numbers, watermarks and backgrounds are "stamps":**
- **In the model,** a document-level list of definitions, each applied to
  a set of pages. Undo and redo cover them.
- **On screen,** they're drawn over the page until saved, like sheaf's
  marks.
- **At save,** they're baked into page content as marked-content artifacts
  the way Acrobat writes them (`/Artifact <</Type /Pagination /Subtype
  /Header>> BDC … EMC`, plus the page's `/PieceInfo /ADBE_CompoundType`).
  Acrobat can then update or remove them, and so can we: Remove strips
  those blocks from the content of files written by either app.

**Crop is per-page state** (a CropBox in the page's own space), written as
`/CropBox` at save. How the view honours it is settled in its slice, after
looking at the page-geometry code.

**Page labels become editable state.** A document-level list of ranges,
anchored to page ids so they survive reorders, written as `/PageLabels`.
Today a rewrite drops the file's labels after any reorder; with the
ranges in the model, they're kept.

## Slices

1. **Combine Files.**
   - The op is `sheaf_ops::combine`: PDFs and images, each with an
     optional page range, an optional bookmark per file (with each PDF's
     own bookmarks nested under it), and images at their own size or
     fitted to Letter/A4.
   - The CLI is `sheaf combine -o out.pdf a.pdf:1-3 scan.tif b.png`.
   - The GUI is File > Create > Combine Files…: a list that can add files,
     add a folder, or take dropped files; reorder and remove; a page range
     per file; the options; then Create (save, then open).
   - The generated-file cache lands here.
2. **Split.**
   - The op `sheaf_ops::split` splits every N pages, by ranges, by
     top-level bookmark, or by maximum file size.
   - The CLI is `sheaf split`, and the GUI Document > Split Document….
   - Splitting the open document includes its unsaved edits.
3. **Insert blank page, insert from images, Replace Pages.** These go in a
   Document > Insert Pages submenu (From File…, From Image…, Blank Page…),
   plus Replace Pages….
4. **Crop pages.**
   - Document > Crop Pages… takes margins or "trim white margins", applied
     to the current, selected, all, or a range of pages.
   - The view, thumbnails, print and export all show the crop, and it's
     saved as `/CropBox`.
5. **Page labels.** Document > Page Labels… sets the style, prefix and
   start for a range. They're shown in the status bar and thumbnails, and
   written as `/PageLabels`.
6. **Headers/footers and Bates numbering.**
   - The text can include the page number, page count, date and file name.
   - Six positions, font size, colour and margins; applied to a range of
     pages.
   - Add, update and remove.
   - Bates gets prefix, suffix, zero padding and a start number.
7. **Watermarks and backgrounds.**
   - Text or image, with opacity, rotation, position and scale.
   - In front of or behind the page content.
   - Add, update and remove.
8. **Bookmark extras.**
   - Create bookmarks from a page range (one per page, titled by label or
     number).
   - Colorize bookmarks by level.
   - Bookmark every match of a pattern, from the Patterns panel.
